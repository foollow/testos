# 样式开发全局规则

本规则要求在处理任何样式相关的 Prompt 时，必须遵循以下标准：

## 1. 优先使用全局 Token
所有样式值（颜色、边框、圆角、特效、字号等）**必须**优先从 `src/index.css` 定义的全局 CSS Token 中选择最接近的变量。

- **禁止**：直接使用十六进制（如 `#FFFFFF`）、RGB、或颜色名称（如 `red`）。
- **必须**：使用 `var(--color-text-2)`、`var(--color-bg-1)` 等。

## 2. 长度单位换算 (Rem)
若 Token 中没有合适的长度定义（如特定间距），必须将像素值 (px) 换算为 `rem` 单位。
- 基准：`1rem = 16px`。
- 公式：`rem = px / 16`。
- **禁止**：直接写死 `px`。

## 3. 动态 Token 选择逻辑
当 Prompt 要求改动样式但未指明具体 Token 时，按以下逻辑自动换算：
- **标题/正文**：根据层级选择 `text-1` 至 `text-6`。
- **背景/表面**：根据容器层级选择 `bg-1..4` 或 `fill-a1..a5`。
- **圆角**：根据视觉尺寸匹配 `radius-4` 至 `radius-full`。
- **边框**：选择 `border-a1` (常用描边) 或 `border-a2` (分割线)。
